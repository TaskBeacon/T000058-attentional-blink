# Task Plot Brief

- Title: Attentional Blink Task
- Construct: temporal attention / target consolidation
- Rows: Short T2 present; Long T2 present; T2 absent (short or long).
- Common phases: fixation 1780 ms; RSVP stream with 50-ms items and 34-ms blanks; post-stream blank 1000 ms; T1 report up to 5 s; T2 report up to 5 s; ITI 200 ms.
- Short row: T1 digit then T2 digit after 336 ms.
- Long row: T1 digit then T2 digit after 672 ms.
- Absent row: T1 digit then an empty T2 position; second response accepts 0 for confident absence.
- Visible RSVP examples should use central black letters and digits on gray participant screens.
- Exact short terms: `Short T2`, `Long T2`, `T2 absent`, `+`, `T1?`, `T2?`, `0 if absent`, `1780 ms`, `50 + 34 ms`, `336 ms`, `672 ms`, `1000 ms`, `5 s max`, `200 ms`.
